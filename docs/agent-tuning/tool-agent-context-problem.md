# Tool Agent 上下文缺失问题图解

## 你遇到的真实场景

```
第 1 轮对话：
  用户："看一下我的论文，答辩会问我什么"
  Agent（RAG）："你的论文是《找搭子系统》，可能问推荐算法、RAG技术..."

第 2 轮对话：
  用户提到了 GitHub 链接 limengyuna/daz-server

第 3 轮对话：
  用户："查看一下我的AI推荐的代码具体是怎么实现的"
  Agent（Tool）："你指的是哪个代码？我需要更多信息..."  ← 问题！它忘了！

第 4 轮对话：
  用户："就是在刚才我发给你的后端服务里面的GitHub链接里面啊"
  Agent（Tool）："我并没有看到您之前发送过具体的 GitHub 链接"  ← 又忘了！
```

---

## 核心原因：LLM 只知道你"喂"给它的内容

LLM 不是人，它没有"记忆"。每次调用 LLM 时，你传什么 messages，它就只知道什么。

---

## 一句话总结

> **LLM 不传历史 = 失忆**。
> 之前修了 Router 和 RAG Agent 的"失忆"，
> 但 Tool Agent 的 Function Calling 还是"失忆"状态。
> 修复方法一样：把对话历史注入到 LLM 的 messages 里。
